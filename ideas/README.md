# ideas/

One folder per idea: `ideas/<slug>/`

| File | Written by | When |
|---|---|---|
| `IDEA.md` | strategist | Card leaves Inbox |
| `BRIEF.md` | analyst | Score, verdict (GO / REFINE / DROP) |
| `SPEC.md` | analyst | Only for GO: user stories, AC-x.y, screens, data, out of scope |

Each idea lives on branch `idea/<slug>` with one PR. Abhishek merges it when approving the build, or closes
it on DROP. Templates are in `templates/`.
